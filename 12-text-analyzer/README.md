# 12 - Text Analyzer 📝

## Description

A powerful text analysis tool that processes any text (direct input or from a `.txt` file) and provides detailed statistics:
- Character and word counts
- Unique words and average word length
- Word frequency ranking (Top 10)
- Clean text processing (removes punctuation and normalizes case)

This is the **twelfth project** in the series. It has a strong **Data Analysis** flavor and introduces:
- Text processing and cleaning
- Frequency analysis with `Counter`
- File reading with `pathlib`
- Professional reporting with formatted output

## How to run

```bash
cd 12-text-analyzer
python main.py
```

You can analyze either pasted text or an existing `.txt` file.

## Concepts learned

- Text cleaning and normalization
- Using `collections.Counter` for frequency analysis
- Working with file I/O using `pathlib`
- Building analytical tools with clear reporting
- Combining multiple string and data analysis techniques
