# 04 - Interactive Calculator

## Description

A full-featured interactive calculator with a menu system. It supports addition, subtraction, multiplication, and division with proper error handling for division by zero. The program runs in a loop until the user chooses to exit.

This is the **fourth project** in the series and marks a significant increase in complexity by introducing:
- Menu-driven interfaces
- `while True` loops with break conditions
- Dictionary of functions (dispatch pattern)
- Robust input validation and error handling
- Type hints with `Callable` and `Optional`

## How to run

```bash
cd 04-interactive-calculator
python main.py
```

## Concepts learned

- Creating and using mathematical functions
- Menu systems and program loops
- Handling division by zero safely
- Using dictionaries to map user input to functions
- Organizing larger programs with multiple functions
- Type hints for functions (`Callable`, `Optional`)
