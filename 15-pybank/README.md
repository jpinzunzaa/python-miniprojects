# 15 - PyBank - Digital Bank 🏦

## Description

A full-featured digital banking simulation with multiple accounts. Users can create accounts, check balances, deposit, withdraw, transfer money between accounts, and view transaction history. All data is persisted in `bank_accounts.json`.

This is the **fifteenth project** in the series. It represents one of the most complete applications so far, combining:
- Multiple user accounts management
- Financial operations with validation
- Transaction history tracking
- Persistent storage with JSON
- Complex menu-driven system

## How to run

```bash
cd 15-pybank
python main.py
```

## Concepts learned

- Managing multiple related records (accounts with transactions)
- Complex financial logic (transfers, balance validation)
- Building a realistic CLI banking application
- Persistent multi-user data management
- Advanced structuring of large interactive programs
