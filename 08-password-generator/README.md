# 08 - Password Generator 🔐

## Description

A secure and professional password generator that creates strong random passwords using the `secrets` module (cryptographically secure, better than `random` for security purposes).

The user can specify the desired length (with a minimum of 8 characters recommended). The generated password includes uppercase, lowercase, digits, and special characters.

This is the **eighth project** in the series. It introduces:
- Secure random generation with `secrets`
- Use of `string` constants (`ascii_letters`, `digits`, `punctuation`)
- Input validation with minimum requirements
- Professional output formatting

## How to run

```bash
cd 08-password-generator
python main.py
```

## Concepts learned

- Difference between `random` and `secrets` for security
- Using `string` module constants for character sets
- Building command-line tools with user-specified parameters
- Input validation and default values
- Creating useful security-related utilities
