# 14 - Inventory Manager 📦

## Description

A complete inventory management system for tracking products. Users can add products, view the current inventory, search for items, record sales (which reduces stock), and see the total monetary value of the inventory.

Data is persisted in `inventory.json` so it survives between runs.

This is the **fourteenth project** in the series. It builds on previous CRUD applications (To-Do, Contact Manager) by adding business logic like sales tracking and inventory valuation.

## How to run

```bash
cd 14-inventory-manager
python main.py
```

## Concepts learned

- Advanced CRUD operations with business rules (stock reduction on sale)
- Calculating derived values (inventory total value)
- Persistent storage with JSON
- Building real-world business tools
- Organizing complex menu-driven applications
