# 01 - Perfil Personal con Inputs

## Descripción

Este mini-proyecto interactúa con el usuario a través de `input()` para recolectar datos personales (nombre, edad, ciudad y profesión) y los presenta en un perfil formateado y profesional.

Es el **primer proyecto** de la serie y establece las convenciones que se seguirán en todos los mini-proyectos:
- Función `main()`
- `if __name__ == "__main__":`
- Uso de type hints
- Validación básica de entrada
- Docstrings claros

## Cómo ejecutar

```bash
cd 01-perfil-personal
python main.py
```

## Conceptos aprendidos

- `input()` para capturar datos del usuario
- Conversión de tipos (`int()`)
- Manejo básico de errores (`try/except`)
- f-strings y formateo de salida
- Estructura modular con funciones separadas
