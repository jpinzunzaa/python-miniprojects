# 01 - Personal Profile with Inputs

## Description

This mini-project interacts with the user through `input()` to collect personal information (name, age, city, and profession) and displays it in a nicely formatted professional profile.

It is the **first project** in the series and establishes the conventions that will be followed in all future mini-projects:
- `main()` function
- `if __name__ == "__main__":`
- Type hints
- Basic input validation
- Clear docstrings

## How to run

```bash
cd 01-personal-profile
python main.py
```

## Concepts learned

- `input()` for capturing user data
- Type conversion (`int()`)
- Basic error handling (`try/except`)
- f-strings and output formatting
- Modular structure with separated functions
