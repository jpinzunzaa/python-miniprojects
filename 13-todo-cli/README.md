# 13 - To-Do CLI ✅

## Description

A complete command-line To-Do List manager with full CRUD operations (Create, Read, Update, Delete). Tasks are saved persistently in a `tasks.json` file so they survive between runs.

Features:
- Add new tasks
- List all tasks with completion status
- Mark tasks as completed
- Delete tasks
- Data is automatically saved to JSON

This is the **thirteenth project** in the series. It introduces:
- Persistent data storage with JSON
- Full CRUD operations on structured data
- Clean menu-driven CLI application
- File I/O with `pathlib` and `json`

## How to run

```bash
cd 13-todo-cli
python main.py
```

## Concepts learned

- Working with JSON for data persistence
- Building a real-world CRUD CLI application
- Managing state across multiple runs of the program
- Organizing larger applications into logical functions
- Using list of dictionaries for structured data
