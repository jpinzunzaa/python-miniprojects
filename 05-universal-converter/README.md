# 05 - Universal Converter

## Description

A comprehensive unit converter that supports bidirectional conversions for:
- Temperature (Celsius ↔ Fahrenheit)
- Distance (Kilometers ↔ Miles)
- Weight (Kilograms ↔ Pounds)

The program features a clean menu interface that continues until the user chooses to exit, with proper input validation and formatted output.

This is the **fifth project** in the series. It builds upon the calculator project by introducing multiple conversion categories and a more organized function-based architecture.

## How to run

```bash
cd 05-universal-converter
python main.py
```

## Concepts learned

- Creating reusable conversion functions
- Bidirectional unit conversions
- Managing multiple categories in one program
- Using dictionaries to map options to functions (`Callable`)
- Building more complex menu-driven applications
- Maintaining clean code structure as projects grow
