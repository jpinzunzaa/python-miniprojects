# 06 - Number Guessing Game 🎯

## Description

A fun and complete "Guess the Number" game where the computer picks a random number between 1 and 100. The player has 7 attempts to guess it, receiving hints if the guess is higher or lower. The game tracks attempts and provides clear win/lose feedback.

This is the **sixth project** in the series. It introduces:
- Random number generation (`random` module)
- Game state management (attempt counter, win/lose conditions)
- Input validation loops
- Multiple rounds support

## How to run

```bash
cd 06-number-guessing-game
python main.py
```

## Concepts learned

- Using `random.randint()` for game mechanics
- Managing game state with counters and loops
- Providing progressive feedback to the player
- Building engaging command-line games
- Structuring larger interactive programs with multiple functions
- Adding replay functionality
