# 03 - Personal Profile v2

## Description

Enhanced version of the personal profile that collects name, age, city and profession, calculates the approximate birth year and the user's age in 10 years, and displays everything inside a nice ASCII art box.

This is the **third project** in the series. It increases complexity by combining:
- Multiple data inputs
- Calculations using `datetime`
- Future projections
- Improved visual output formatting

## How to run

```bash
cd 03-personal-profile-v2
python main.py
```

## Concepts learned

- Using `datetime` for current year calculations
- Projecting future values (age + 10)
- Creating ASCII art borders for better UX
- Organizing code with multiple specialized functions
- Progressive enhancement of previous concepts
