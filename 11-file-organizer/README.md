# 11 - File Organizer 📁

## Description

An automatic file organizer that scans a folder and moves files into categorized subfolders based on their extensions (images, documents, videos, audio, and "others").

The program uses the modern `pathlib` module and provides clear feedback during the organization process.

This is the **eleventh project** in the series. It introduces:
- File system operations with `pathlib`
- Automatic file categorization by extension
- Safe file moving with conflict handling
- Practical automation tool for everyday use

## How to run

```bash
cd 11-file-organizer
python main.py
```

Then enter the path of the folder you want to organize.

## Concepts learned

- Working with `Path` objects from `pathlib`
- File type detection using suffixes
- Organizing files into category folders
- Safe file operations (`mkdir`, `rename`, `exists`)
- Building practical utility scripts
- Progressive complexity in file system automation
