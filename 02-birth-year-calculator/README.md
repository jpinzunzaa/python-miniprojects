# 02 - Birth Year Calculator

## Description

This mini-project asks the user for their name and age, then uses Python's `datetime` module to calculate and display the approximate year they were born.

It is the **second project** in the series, increasing complexity by introducing:
- Import from the standard library (`datetime`)
- Simple arithmetic based on current date
- Basic input validation

## How to run

```bash
cd 02-birth-year-calculator
python main.py
```

## Concepts learned

- Working with `datetime.now().year`
- Basic calculations with user input
- Input validation loops
- Separation of concerns (data collection, calculation, display)
