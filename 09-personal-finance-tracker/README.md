# 09 - Personal Finance Tracker 💰

## Description

A complete command-line personal expense tracker. Users can add expenses with description, amount, and category, view all recorded expenses, and see a summary with totals and breakdown by category.

This is the **ninth project** in the series. It introduces:
- Working with lists of dictionaries for data storage
- Basic data analysis (grouping by category, calculating totals and percentages)
- A clean menu-driven interface
- Separation of concerns with multiple functions

## How to run

```bash
cd 09-personal-finance-tracker
python main.py
```

## Concepts learned

- Managing structured data with dictionaries
- Grouping and aggregating data (by category)
- Building interactive data management tools
- Calculating percentages and summaries
- Organizing larger applications with multiple responsibilities
