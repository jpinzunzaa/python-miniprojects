# 10 - Contact Manager 📱

## Description

A full-featured command-line contact book (CRUD application). Users can add, list, search, update, and delete contacts. Each contact stores name, phone number, and email.

This is the **tenth project** in the series. It represents a significant step in complexity by implementing a complete CRUD (Create, Read, Update, Delete) system with a clean menu interface and helper functions.

## How to run

```bash
cd 10-contact-manager
python main.py
```

## Concepts learned

- Full CRUD operations on a list of dictionaries
- Search functionality across structured data
- Updating mutable data structures safely
- Building a complete interactive application
- Organizing code into logical functions (`add_contact`, `update_contact`, etc.)
- Progressive complexity in data management applications
