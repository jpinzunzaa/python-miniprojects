# 07 - Rock, Paper, Scissors ✂️

## Description

A complete "Rock, Paper, Scissors" game against the computer. First player to win 3 rounds wins the match. The game includes input validation, score tracking, clear feedback, and engaging messages with emojis.

This is the **seventh project** in the series. It builds on the guessing game by introducing:
- Classic game logic with win conditions
- Persistent score across multiple rounds
- Best-of-3 format
- Robust input validation

## How to run

```bash
cd 07-rock-paper-scissors
python main.py
```

## Concepts learned

- Game logic and win condition evaluation
- Score tracking across multiple rounds
- Using sets or tuples for winning combinations
- Building engaging two-player (vs computer) games
- Input validation with loops
- Progressive complexity in game development
